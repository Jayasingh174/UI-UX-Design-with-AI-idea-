# 🌸 Radha Krishan Resort Management System

A **UI/UX design and web interface project** for a Radha Krishan Resort Management System, focused on creating a clean, user-friendly experience for resort guests, staff, and administrators.

The project includes multiple interface designs, dashboards, login screens, room-management pages, guest pages, and supporting design concepts.

## ✨ Project Overview

The **Radha Krishan Resort Management System** is designed to simplify resort operations through dedicated interfaces for different users.

### Main Areas

* 🏨 Resort / Guest Management
* 🛏️ Room Selection and Management
* 👤 Guest Login and Guest Pages
* 👨‍💼 Staff Login and Staff Dashboard
* 🔐 Manager / Admin Management
* 📊 Management Dashboards
* 🎨 UI/UX Design Concepts
* 🤖 AI-assisted design ideas
* 🌐 Web interface prototype

## 🎯 Objectives

* Design an intuitive resort management interface.
* Create separate experiences for guests, staff, and management.
* Improve navigation and usability.
* Develop consistent UI components and page layouts.
* Explore how AI can assist in UI/UX design and project development.

## 👥 User Roles

### Guest

* Login

### Staff

Staff interfaces are designed for:

* Staff authentication
* Dashboard access
* Resort operations

### Manager / Admin
